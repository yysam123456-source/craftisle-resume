Craftisle Resume

Build a resume in the browser with Craftisle Resume

Craftisle Resume is a resume builder that runs as a single-page web app. It offers fifteen section types — profiles and contact links, summary, experience, education, projects, skills, languages, awards, certifications, publications, volunteer work, interests, references, cover letters and custom sections — and fifteen visual templates to pour them into. When the document is ready it exports to PDF or DOCX. There is no account to create and no upload step: your drafts live in the browser.

What you can build

  • Fifteen resume templates — Azurill, Bronzor, Chikorita, Ditgar, Ditto, Gengar, Glalie, Kakuna, Lapras, Leafish, Meowth, Onyx, Pikachu, Rhyhorn and Scizor. Each template is a layout over the same content, so switching design never means retyping a section.
  • Fifteen section types from summary and experience through awards, publications and volunteer work, plus custom sections for anything the standard set misses.
  • Live preview — edit a section and the page re-renders in place, showing what the exported document will contain.
  • PDF and DOCX export — the PDF is generated in the browser from the same layout you were editing; DOCX suits application portals that insist on Word files. A JSON export holds the raw resume data.

How it works

Resumes are stored in your browser's local storage under the key craftisle-resumes, not on a server. Exporting builds the file on your machine: nothing is uploaded, and there is no account, sign-in or share link. This also means a resume belongs to one browser — export the JSON before clearing site data if you want to move it elsewhere.

What it does not do

It is a document tool, not a job service: it does not apply to jobs, match you with employers or score your resume against an applicant-tracking system. AI assistance, public share links and built-in statistics are not available in this deployment, so proofread the text before you export it.

Questions

Is Craftisle Resume free?

Yes. Every template and every export is available without a paid plan, and no feature is locked behind an account.

Where is my resume stored?

In your browser's local storage, under the key craftisle-resumes. It is not sent to a server, which is also why it does not follow you to another device.

Can I export to Word?

Yes. The export panel produces a DOCX file as well as a PDF, so a resume can be submitted to portals that only accept Word documents.
